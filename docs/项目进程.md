### 新增功能

- 提供 `doctor`、`ask`、`chat`、`sessions` 等基础命令和流式事件输出。
- 接入 OpenAI 兼容 Provider，以及文件读取、写入、精确编辑、搜索、计算和时间工具。
- 增加配置校验、稳定错误类型、最大步数保护与工作区路径安全检查。

### 运行实现

- CLI 从 `.env` 和环境变量加载 Settings，创建 Runtime 后为请求分配 Session 与独立工作区。
- Agent 在工作区内调用受限工具；绝对路径、父目录穿越和链接逃逸会在执行前被拒绝。
- Runtime 将模型与工具执行过程转换为 CLI 可消费的流式事件。

### 新增功能

- Planner 生成计划与验收条件，Actor 执行实现，Verifier 根据结构化证据判断是否完成。

- Final 节点根据最终状态生成稳定输出，不再触发工具调用。
